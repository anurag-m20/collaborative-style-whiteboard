# React Canvas Whiteboard

A feature-rich single-user whiteboard built with React
and HTML5 Canvas.

## Features

- Freehand drawing
- Rectangle, circle and line tools
- Text and sticky notes
- Move and resize elements
- Multi-selection
- Group / Ungroup
- Copy / Cut / Paste
- Undo / Redo
- Layers
- Zoom and Pan
- LocalStorage persistence
- PNG export
- Keyboard shortcuts

## Tech Stack

- React
- JavaScript
- HTML5 Canvas
- CSS
- LocalStorage
- Vite
